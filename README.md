# ⚡ SkillBridge AI — Real-Time Career Intelligence

A Streamlit-powered career readiness and real-time job market skill gap analyzer.

## Features
- **Live Job Market Scraping (`python-jobspy`):** Pulls recent postings for your target company, role, and location.
- **Structured AI Skill Extraction (`google-genai`):** Extracts demand percentages, priority tiers, and capstone project recommendations.
- **Interactive Analytics:** Real-time skill demand comparison bar charts, category competency radar charts, and a week-by-week sprint roadmap.

## Quickstart
```bash
pip install -r requirements.txt
export GEMINI_API_KEY="your-api-key"
streamlit run app.py
```
